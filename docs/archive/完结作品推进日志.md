     **不为此新增 sha2 依赖**；规范化串对每段带长度前缀，并有专门测试守住边界漂移
     （「标题 ab+正文 c」与「标题 a+正文 bc」必须不同指纹）。
  4. `delete_work_version` 只回传产物相对路径、**不假装会删磁盘文件**：删文件需要作品库根，那是 B3 的产物。
