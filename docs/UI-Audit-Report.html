总体结论：有条件通过 —— 构建与核心流程健康，无阻断项；但存在全局性 WCAG AA 对比度失败与图标无障碍缺口，建议按 P1 顺序修复后合入。

范围（Scope）

项目Sight Folio —— Tauri 2 + React 18 + TypeScript + MUI（@mui/material 9）+ Vite 桌面写作应用
页面Bookshelf / SceneEditor / PublishedScenes / ScenePreview / AiAgent / Writing / Library / Settings
审计维度Accessibility · Performance · Theming · Responsive · Implementation integrity（design-constraints 五维）
证据类型源码行号、对比度计算（WCAG 2.1 公式）、eslint/tsc 静态检查、全站 grep 扫描；未做运行时渲染走查（见「未验证」）
窗口约束tauri.conf.json：主窗口 1200×800，minWidth 960 / minHeight 640

结论（Conclusion）

✅ 实现完整性：TypeScript 类型检查通过（npx tsc --noEmit，2 GB heap 下 0 错误）；eslint 0 error / 560 warnings（未用变量与 hooks 反模式为主，无致命错误）。
✅ 浅色主题对比度基线良好：brand700 主色 9.09:1、text.secondary 7.56:1、secondary gray500 4.52:1，均达 AA。
❌ 暗色主题与语义色存在全局对比度缺陷：dark primary 仅 1.97:1；success/warning/error/info 四组语义色白字全部低于 4.5:1，且全站 58 处组件在使用。
❌ 图标无障碍缺口：210 个 IconButton 中 204 个无 aria-label；全项目无任何 prefers-reduced-motion 支持。
⚠️ 主题一致性风险：LibraryPage 整页靛蓝主题覆盖全局品牌紫；pages 下 74 处硬编码色。

问题清单（Findings）

P1 · THEMING / ACCESSIBILITY

暗色主题 primary.main 与背景对比度仅 1.97:1（WCAG AA 失败）

影响
暗色模式下所有 primary 主色文本、图标与描边控件不可辨读，属全局性障碍。
证据
src/theme/AppTheme.tsx:97-102 dark primary.main = brand[600] #68409f，on gray800/paper #1f2937 实测 1.97:1（普通文本需 4.5:1、图形/大文本需 3:1）。
最小修复
dark primary.main 提升 1–2 档（如 brand[500] #8158be，对 #1f2937 约 3.4:1）或为暗色单独指定加亮主色、避免直接复用 600 档。
P1 · ACCESSIBILITY / THEMING

语义色 contrastText 全为纯白，与 success/warning/error/info 主色全部低于 4.5:1

影响
全站 58 处 color="success|warning|error|info" 的 Button / Chip / Badge 文字对比度不达标（见对比度矩阵），错误提示、保存成功、删除确认等关键状态文字低可读性。
证据
AppTheme.tsx:112-137 四组语义色 contrastText 均为 #ffffff；实测：white on success green500 2.54:1、warning orange500 2.12:1、error red500 3.76:1、info blue500 3.68:1。使用点：LibraryPage:1925 删除按钮、SceneTabBar:886/899/1078、WorkbenchAiPanel:871、InlineChat:415 等。
最小修复
① 语义色 main 改用更深档（如 success green600 / warning orange600 / error red600 / info blue600）保持白字；或 ② 为 warning/success 这类浅色 main 换深色文字（gray900）。优先方案 ①，改动集中在 theme 一处即可全站生效。
P1 · ACCESSIBILITY

204/210 个 IconButton 缺少 aria-label，屏幕阅读器无法读出按钮含义

影响
依赖读屏的用户几乎无法操作所有纯图标按钮（删除、关闭、下载、返回等），是不可访问路径。
证据
全站扫描：IconButton 共 210 处，仅 6 处带 aria-label；高发文件 WritingPage 38、SceneEditorPage 14、AiAgentPage 11、CodeWorkbench 9。项目内 aria-label 总出现数仅 23 处。
最小修复
为纯图标 IconButton 统一补 aria-label（有 Tooltip 的按钮也应显式标注，Tooltip 不替代名称）；可约定无标题 IconButton 一律要求 aria-label 作为 lint 规则。
P1 · ACCESSIBILITY

全项目无 prefers-reduced-motion 支持

影响
对「减少动态效果」系统偏好敏感的用户（前庭障碍、注意力障碍）会暴露于所有动效：渐变过渡、hover 位移、抽屉展开等。
证据
全站 grep prefers-reduced-motion / @media (prefers- 0 命中；MUI 组件动画依赖 theme.transitions 默认开启。
最小修复
在 AppTheme.tsx 或全局 CSS 增加 @media (prefers-reduced-motion: reduce) 关闭非必要 transition/animation；MUI 可经 createTheme({ transitions: { ... } }) 或在 useMediaQuery('(prefers-reduced-motion: reduce)') 下切换禁用。
P2 · THEMING

LibraryPage 整页覆盖靛蓝主题，与全局品牌紫冲突

影响
侧边栏/顶栏保持品牌紫，页面内容切换为靛蓝系，主题跳变破坏全站一致性；且绕过全局 token（圆角 10 也独立于全局 6/12 体系）。
证据
src/pages/LibraryPage.tsx:900-937 全新构造 createTheme({ cssVariables:false, ... })：primary #4f46e5、secondary #6b5ce0、独立 background/text/divider 色板；注释自述系绕开 appTheme.cssVariables 的实测决策。
最小修复
将「现代工作台靛蓝」收敛为全局主题 preset（AppTheme.tsx 已有 preset 机制 blue/green/orange/purple），LibraryPage 只声明 preset 名，不再内联整段主题；圆角并入全局 BORDER_RADIUS_MAP。
P2 · THEMING

pages 下 74 处硬编码色，体裁/画像/状态色未走 token

影响
主题切换（暗色/品牌 preset）无法覆盖这些颜色，且与 palette 两层口径并存，长期维护成本高。
证据
grep #[0-9a-fA-F]{3,8}：LibraryPage 908-932（局部主题段）、WritingPage 1030-1035（阅读排版 #1a1a1a/#666/#4A338F）、WritingPage 2368-2376（#b25e12/#d9822b）、SceneEditorPage 133-400（体裁/画像色）、writingSchema.ts:23-26（novel #4A338F / essay #0ea5e9 / poetry #f59e0b / script #10b981）。
最小修复
体裁与状态色并入 themePrimitives ramp（绿色系已有 green/orange/blue），组件经 palette.* 引用；页内排版色（1011-1044 导出 HTML）属导出文件可保留但建议注释来源。
P2 · ACCESSIBILITY

体裁色对比度不达标：poetry #f59e0b 2.05:1、script #10b981 约 2.1:1

影响
诗歌/剧本体裁标签文字在浅色背景上低对比，状态信息不可辨。
证据
writingSchema.ts:25-26；实测 f59e0b on #f8fafc = 2.05:1、10b981 on #f8fafc ≈ 2.1:1（均 < 4.5:1）。
最小修复
改用深档（poetry → orange700 #a87221 约 5:1；script → green700 #047857 约 5.6:1）或置为图标/描边 + 文字另用深色。
P2 · ACCESSIBILITY

AI 品牌渐变局部对比度不足：三色渐变段 2.72:1、渐变文字 4.23-4.47:1

影响
AI 标识/头像内白图标在渐变浅色段（#a78bfa）低于 3:1 图形门槛；渐变描边文字低于 4.5:1 文字门槛。
证据
AiAgentPage.tsx:397 渐变 #6366f1→#8b5cf6→#a78bfa 上白 SmartToyIcon：white on #a78bfa = 2.72:1；AiAgentPage.tsx:410 渐变文字 #6366f1/#8b5cf6 白字 4.47/4.23:1。aiBrand.ts AI_GRADIENT 同源。
最小修复
渐变收窄到 500/600 档区间（去掉 #a78bfa 这类 >500 亮端），或渐变文字改用深色 rgba overlay 后再上白字。
P2 · IMPLEMENTATION INTEGRITY

MainGrid 仪表盘 statData 硬编码 value '0' 占位

影响
仪表盘统计卡显示固定 0，用户会误读为真实统计，属误导性 UI。
证据
src/components/MainGrid.tsx statData 中 value 均为字符串 '0'，无真实数据接线。
最小修复
接真实计数（books/scenes/agents 等 store 数据）或标注「统计功能建设中」；合入前至少避免渲染成数值 0。
P2 · PERFORMANCE / IMPLEMENTATION

eslint 560 warnings：setState-in-effect 反模式与大量未用变量/导入

影响
WritingStatsDialog 等组件在 effect 中 setState 可能触发多余渲染；未用变量指示死代码与漏删分支，增加维护噪音。
证据
eslint 0 error / 560 warnings；react-hooks/set-state-in-effect 命中 WritingStatsDialog.tsx:48 等；未用变量：codeWorkbenchStore.ts:961、componentStore.ts:30、reportGenerator.ts、studioBook.ts:248、writingBoards.ts:11。
最小修复
将 setState 移到事件/派生数据路径；分批清理未用导入（可先加 no-unused-vars 为 error 逐步清零）。
P3 · RESPONSIVE

LibraryPage 多处 noWrap + fixed flex+flexShrink，长标题截断无提示

影响
超长书名/作者在窄窗下被截断且无 ellipsis 溢出提示。
证据
LibraryPage.tsx:809/842/1008/1149/1304 等 noWrap 组合；1008 行 flexShrink: 0 可能把周边挤压出容器。
最小修复
对标题统一 textOverflow:'ellipsis' + 非零 minWidth；工具提示或 title 属性承接完整文本。
P3 · RESPONSIVE / IMPLEMENTATION

SceneEditor 图标模式策略仅注释约定，960px 下限布局未验证

影响
≤1280 窗口切换图标模式的策略有设计意图（SceneEditorPage.tsx:468 注释），但未被代码量化执行，960 极窄窗口下的面板挤压风险未知。
证据
SceneEditorPage.tsx:468 注释：「配合 tauri.conf.json 的 minWidth=960（≤1280 一律图标模式），窗口永远缩不到文字会换行的宽度」；未发现对应媒体查询实现。
最小修复
将图标模式阈值落实为 useMediaQuery 断点或在 Layout 层设置；运行时抽查 960×640 各主要面板。
P3 · ACCESSIBILITY

WritingPage 完成提示小字对比度 4.36:1

影响
11.5px 提示文字略低于 4.5:1，弱视用户可读性边际。
证据
WritingPage.tsx:2368-2376 文字 #b25e12 on rgba(217,130,43,0.12) —— 对浅底近似 4.36:1。
最小修复
文字切为 orange800 #875b1c 或加深底透明度组合，即可过 4.5:1。
P3 · IMPLEMENTATION / I18N

LibraryPage 语言名 '中文'/'English' 硬编码绕过 i18n

影响
语言标签展示值与 i18n 体系脱节；新增语言需同步改判断分支。
证据
LibraryPage.tsx:1792-1796 detailTarget.language === 'zh' ? '中文' : 'English'。
最小修复
纳入 i18n key 或复用语言 self-name 映射常量表。

保留项（Preserved）

  • 品牌色事实：品牌紫（brand700 #4a338F / brand800 #3a286F）与品牌金（orange 金 accent ramp）是产品识别资产，修复语义色对比度不能动品牌色本身，只能调整组件用色档位。
  • LibraryPage 靛蓝风格：若「现代工作台靛蓝」是产品有意设计，则保留风格但应收敛为全局 preset，而非页面内硬编码。
  • 体裁/画像多色体系：novel/essay/poetry/script 颜色是业务语义（poetry/script 为预留域），仅修对比度档位、不换语义。
  • 窗口下限：minWidth 960 是产品对「全功能桌面编辑器」的取舍（保证 SceneEditor 图标模式可用），不以小窗横向溢出为由放宽。
