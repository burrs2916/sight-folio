## 5. 🆕 记账方法纠正（会直接影响下一轮的判断）

本轮先用第六次审计 §5 的老办法（按符号名 grep 计数）复核，当场拿到两个**假读数**：

```
colorSchemes -> 3 files      shape -> 19 files     ← 全是假阳性
```

原因：`colorSchemes` / `shape` 是常见词，别人在自己文件里定义同名局部量/键名都被数进来。

```bash
rg -n --multiline -U "import\s*\{[^}]*\}\s*from\s*'[^']<模块名>'" src -g '*.ts' -g '*.tsx'
```
