## 3. 实测缺口清单（下一轮的落刀点，按性价比排序）

### 3.1 字体大小：档位机制齐全，**覆盖率**是缺口（最高性价比）
`rg -o "fontSize:\s*[0-9]+" src/ --glob '!src/theme/**' --glob '!src/**/__tests__/**' | wc -l` = **2758 处**硬编码 px；
而 `uiFontSize()` 的消费者只有 **8 个文件**（设置抽屉 / 顶栏 / 侧栏 / MenuContent / 备份区 / 健康提示 / 写作台面板）。
即：切「字体大小」档位时，**设置面板自己变、主界面大面积不变** —— 这就是用户看到的「字体大小设置没生效」。

`AiAgentPage.tsx` 112 / `EntityPortraitPanel.tsx` 107 / `ComponentCenterPanel.tsx` 93 /
