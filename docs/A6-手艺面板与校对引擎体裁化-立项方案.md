## 一、病灶（代码事实，非推测）

### 1) 本地校对引擎：有"组级裁剪"，无"句法级豁免"
- `buildProofreadReport(chapters, …, genre)` 的 genre 只用在 **line 620 一处**：
  `kept = genre ? issues.filter(i => proofreadGroupVisibleForGenre(genre, i.group)) : issues`
  —— 这是**组级**：日记没伏笔就整组 `fs:*` 不报。✓ 已做。
- 但逐章规则 `chapterTextIssues(chapter)`（`writingProofread.ts:104`）**签名里没有 genre、也不读 genre**，对五种体裁一视同仁跑这套小说句法：
  - `LongParagraph`（line 140）：单段 >600 字判长 —— **剧本一整幕的对白天然很长**，会被误报。
  - `RepeatPunct/RepeatChar`（130/135）：叠词/连标点 —— **诗歌复沓、"啊啊啊"是修辞**，会被误报。
  - `BlankLines`（148）：≥3 空行 —— **诗的节距**正靠空行，会被误报。
  - `QuoteMix`（151）：引号混用 —— 剧本括注+台词混排易误判。
  - 还有 `runProofread(text)` 引擎级（typo/repeat/sensitive）同样小说口径。

### 2) 四个手艺面板：0 处 genre 引用，核心度量按小说句法
- `AiFlavorPanel / ShowTellPanel / EmotionArcPanel / CraftComparePanel`（均在 `src/pages/writingPage/`，由 `WritingPage.tsx:5313/5350/5385/5517` 渲染）。
- 四者的 Props 接口（如 `EmotionArcPanelProps`）**都没有 genre**，要接体裁必须先扩 props。
- 底层度量在 utils（`emotionArc.ts` 等）按小说情绪弧线/显性叙事建模；剧本看"对白推动"、诗看"意象密度"，口径不同。

### 3) 已存在但**没接进校对**的体裁基建（好消息，不是从零）
- `poetryForms.ts`：完整诗形式度量（五言/音节估算/节结构），**自带 `readPoemForm(chapter.extra)`，无需 genre 参数**，且写明诚实边界——"语种不匹配就不下判定、返回 `measureSkipped`，绝不产出'每句12字不符'这种废话"。
  - 现状：被 `ChapterTreePanel`/`writingStore`（存形式）消费，**唯独没进 `chapterTextIssues`**。
- `viewKindVisibleForGenre` / `proofreadGroupVisibleForGenre`：体裁可见性真源，可直接复用做裁剪。

## 二、为什么它"没有安全接线子项"（推翻我前几轮的部分猜测）

我一度以为 A-6 能拆出"像洼地②那样零风险接线"的子项，逐一核后**结论是否定的**：
1. **poetryForms 接入 = 加新规则，不是换文案**。要把诗形式校验塞进 `chapterTextIssues`，得给它**加 genre 入参**——而该函数被 **4 处消费**（WritingPage:931 / WritingChapterEditor:173 / writingCorpus:471 / writingProofread:442），改签名波及面大，且属于**给诗集新增告警**（改变输出），不是零回归接线。
2. **句法豁免 = 删除既有告警**。让诗不报 LongParagraph/BlankLines，是要在 `chapterTextIssues` 里按 genre `if` 跳过规则——同样要改这个 4 处消费函数，且"哪些规则对哪体裁豁免"是**逐条产品判断**（如：诗的 RepeatPunct 豁免，但日记的要不要？），报告没细化。
3. 四面板扩 genre + 底层度量分体裁，是**实打实的功能开发**。

## 三、若开工，建议的分期（每期独立可验证、独立可回滚）

## 附：实测证据（2026-11-14 探针，覆盖正文的猜测）

用一次性 vitest 探针（跑完已删）对 `chapterTextIssues` 喂各体裁典型文本，实测真实判定，**校正上文 §一/§五 的推测**：

| 输入（典型体裁文本） | 实测 messageKey | 结论 |
|---|---|---|
| 诗·节间 1 空段 `<p></p>` | `StructEmptyPara` | **真误报**：诗分节的空段被当"空段病" |
| 诗·节间 ≥2 空段 | `StructEmptyPara` + `BlankLines` | **真误报**：诗的节距被报"连续空行" |
| 剧本·省略号沉默 `……（沉默）……` | `RepeatPunct` | **真误报**：戏剧留白被当重复标点病 |
| 剧本·破折号 `——` | （无） | 不破 |
| 剧本·单段长对白(~180字) | （无） | **不破**——`LongParagraph` 阈值是 600 字，单段对白基本够不到。**上文"剧本豁免 LongParagraph"是误判**，撤回 |
| 小说·中英文引号混用 | `QuoteMix` | 正确（该报） |

### 据此修正的豁免清单（证据驱动，替代上文初稿）
- **poetry**：`StructEmptyPara`、`BlankLines`（节距）；`RepeatPunct`/`RepeatChar` 是否豁免需再确认（诗复沓标点如"……"也常见）。
- **script**：`RepeatPunct`（戏剧省略号/沉默留白）；**不必**豁免 LongParagraph（实测不触发）。
- **novel / essay**：空集（零回归）。

### 对 §三 路线的影响
- A6-1 仍需给 `chapterTextIssues` 加 genre 入参（4 处消费函数，硬前提不变）。
- 但豁免面比初稿**更小更准**：主要是诗的空行/空段 + 剧本的省略号，不是大面积关规则。
- 仍需用户拍板"诗复沓标点、剧本其它句法是否也豁免"——但已有实测锚点，不再是空猜。

## 附二：A6-1 豁免边界取证收敛（2026-11-14，5体裁×19种典型文本矩阵）

为确认豁免集是否够用，穷尽跑了 19 个体裁典型样本（诗：br换行/叠字/现代长句/多节/重章叠句；剧本：短对白/省略号/括号指示/幕场标记/12轮密集对白；日记：口语/日期/多感叹/流水账；散文、小说对照）。结论：

**① 已豁免的三类误报之外，没有新的"体裁本体被当病"确凿证据**：
- 诗经式重章叠句（蒹葭三章）**不触发** RepeatPhrase —— 引擎口径本就够宽，无需豁免。
- 叠字修辞（寻寻觅觅冷冷清清）**不触发** RepeatChar —— 规则只抓三连（了了了），两连叠词本就不报。
- 真实 12 轮密集对白**不触发**任何规则 —— 无需为剧本豁免 RepeatPhrase。

**② 仍有触发但判定为"跨体裁通用提醒、不应按体裁豁免"**：
- `RepeatPunct`：日记"！！！"→ 小说同样会打"！！！"，非体裁特有，保留报。
- `StructPanguSpace`（中西文间隔）：日记"早上7点起"→ 通用排版建议，保留。
- `RepeatPhrase`：仅在极端重复时触发，保留。

**③ 最终豁免集（与 A6-1 实装一致，未再扩大）**：
poetry = {StructEmptyPara, BlankLines}；script = {RepeatPunct}；novel/essay/diary = ∅。

**纪律结论**：若凭"诗有叠字/剧本有重复称呼"的直觉扩大豁免，会砍掉 typo/重复用词等真功能（违背"不砍功能"原则）。本次矩阵正是用来**证明不该扩大**的取证。已将该边界固化为回归锁测试，防止将来改引擎阈值时把体裁特征改回误伤。
