## 二、产品蓝图：画布 = 作品的多板工作台

书=场景（F7）之后，**视图机制 = 一本书的多块板**，这是整个蓝图的承重墙：

```
一本书（场景）
 ├─ 板1 全书总览（默认）：章节卡按卷分组 + 人物节点 + 出场边（F8-G2）
 ├─ 板2 分镜板：自由拖拽章节节拍卡 + 插画 + 文字注记
 ├─ 板3 人物关系板：人物节点 + 关系边（可点击跳设定卡）
 └─ 板4 封面/宣传板：插画 + 标题排版 + 装饰
```

创作闭环：**解析（自动产板）→ 人工拖拽/插画排版 → AI 修改优化 → 定稿回写作台**。

## 四、验收口径（画像价值铁律不变）
每块板/每个按钮三问：①用户能不能看出这块板是干什么的 ②给的信息是不是创作要的 ③点了有没有事发生。AI 每次修改必须可预览、可撤销、可拒绝——平台不擅自改用户的作品。
