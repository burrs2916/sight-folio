## 0. 一句话结论

**目录树的父子关系在快照里是完整的（`kind` + `parent_id`），封面图在库里也是完整的（`writing_chapters.extra.coverImage` + `covers-<bookId>/`）——是"快照 → 渲染"这一步既没读结构、也没读封面，而且封面的三层（书封 / 卷封 / 章封）分别断在三个不同的地方。**

- 顺序 + 父子：**零 schema 改动**，已锁的 v1 也能立刻导对（沿用 11-05 方案第 1 步）。
- 卷封 / 章封：**必须给快照表加一列 `cover`（schema_ver 1→2）**。这是本文与 11-05「零 schema」结论的唯一分歧点，且分歧原因明确：11-05 只管结构树（快照已有），封面确实不在快照里。
- 书封：**零 schema**，与"渲染当时现取书名/简介"同一口径顺带取，不必进快照。

## 2. 三个缺口（互不重叠，各自可独立验证）

### A. 结构在"快照 → 载荷"这一步被丢弃，顺序未按树先序
| 位置 | 病灶 |
|---|---|
| `export_jobs.rs:515-525 snapshot_to_epub_chapters` | 写死 `volume: None, cover: None`；注释称「快照表没有 cover/volume 列…本就不存在」——**前半句对，后半句对 volume 错**：分卷关系在 `kind + parent_id` 里，快照存了。这句注释把"可做"写成了"不存在"，于是 P0 直接放弃 |
| 同一函数 `chapters.iter()` 平铺 | 未按先序展平：卷节点混在章里各出一个空页（11-05 §2 病灶②） |
| `work_version/mod.rs:74-93 build_snapshot` | `sort_order` 密集重编自 `list_chapters` 的扁平序（`writing_repository.rs:510` `ORDER BY sort_order`）→ 快照继承"非先序"这个错序 |

### B. 渲染器层级能力不齐（`EpubChapter.volume` 那条注释是假注释）
| 格式 | 现状 | 证据 |
|---|---|---|
| EPUB | 只认 `volume` 字符串做**连续分组**，卷组标题用 `<span class="nav-volume">`（不可点、阅读器不成树）；卷自身仍是独立空页 | `writing/mod.rs:458-486` |
| PDF | 已支持两级：正文居中卷题 + 目录卷层缩进 | `pdf_export.rs:205-232 / 812-840` |
| DOCX | **`volume` / `cover` 出现 0 次**，全部 `heading2_paragraph(&ch.title)` 平铺，无封面页、无 TOC 字段 | `docx_export.rs:102-113` |
| HTML / TXT / MD（快照原生） | 零层级（`<h2>` 平铺 / 无卷题 / `##` 平铺）；而前端「另存为」自己那三份**有**卷处理 → 同一件事两份实现、快照版还更弱 | `export_jobs.rs:707 / 727 / 979` vs `useExportActions.ts:212 / 264` |

### C. 封面三层全断，且断在三个不同地方
| 层 | 唯一真源 | 断点 |
|---|---|---|
| **书封** | 素材库 `data/assets/writing/covers-<bookId>/` 首个文件（「有文件=有封面」，零 DB 字段）：`BookshelfPage.tsx:105-112`、`BookMetaPanel.tsx:61-63` | 导出侧**零接入**：EPUB `cover.xhtml` 纯文字（`writing/mod.rs:588-613`）+ OPF 无 `cover-image`；PDF `build_cover_stream(title, description, glyphs)` 纯文字（`pdf_export.rs:198, 789`）；DOCX 连封面页都没有 |
| **卷封** | 卷节点 `extra.coverImage`（库里实测卷 1 有） | **快照表无 `cover` 列**（`migration.rs:1660-1670` 只有 9 列）→ 锁定即丢，导出无从取 |
| **章封** | 章节点 `extra.coverImage`，口径 `parseChapterCover` | 同上快照丢；只有写作台「另存为」还带着（`useExportActions.ts:189/299/327`），但那条路径把卷节点当普通章，封面挂错位置 |

**必须沿用的既有定稿**（`writingOutline.ts:153-158`）：封面**各自独立、绝不向上借用**。导出侧禁做"沿 parentId 上溯借卷封面给章"——那是已废弃的千篇一律。章封=章自己的 extra，卷封=卷自己的 extra，书封=`covers-{bookId}`。

## 3. 施工批次（顺序即依赖；每批独立可验，全部收敛在渲染层 + 一处 schema）

### B-a｜结构重建与先序展平（解 A；= 11-05 方案第 1 步）
把 `snapshot_to_epub_chapters` 换成纯函数 `snapshot_to_export_tree`：
1. 由快照行建 `byId(src_chapter_id)` + `hasChildren` + `legacy`（全书无 parent → 走遗留 `volume` 字符串，旧书零变化）；
2. 容器判据复用既有口径（`writingStats.ts:21/47-52 STRUCTURE_KINDS={'卷','篇'}` ∪ 确有子级），在 Rust 侧同一判据落一份纯函数，注释里点名来源，禁另立枚举；
3. 输出顺序 = **先序**（容器紧跟其子章）；内容章的 `volume` = 最近卷级祖先标题；
4. 卷节点输出为「卷页」载荷（标题 + 卷封面 + 可选卷首语），不再混进章列表。
零 schema、零回填，已锁 v1 立即导对。

### B-b｜封面入链（解 C，本文新增）
1. **快照加列**：`work_version_chapters` 增 `cover TEXT NOT NULL DEFAULT ''`（ALTER 幂等，与 `migration.rs` 现有加列范式一致）；`SNAPSHOT_SCHEMA_VER: 1 → 2`；`build_snapshot` 用与前端 `parseChapterCover` 同口径解析 `extra.coverImage` 透传。
2. **旧版诚实**：`schema_ver=1` 的历史版本没有 cover → 导出无图，**绝不回读活章节脑补**（`export_jobs.rs:434` 红线保留）。UI 上把这条如实写进版本详情的排版说明（"该版锁定于封面入链之前，产物不含章头图"）。
3. **指纹纳入 cover**：`content_fingerprint` 目前哈希 title/content/kind/parent_id/status（`mod.rs:52-67`）。建议加 cover —— 否则"只换章头图"会被 `SAME_CONTENT` 拦成"内容没变"，合法重锁锁不出来。历史指纹不重算，仅新锁生效。
4. **书封零 schema**：`render_job` 已经"渲染当时"从 `writing_books` 现取书名/简介（`export_jobs.rs:444-456`），同一口径再取 `covers-<bookId>/` 首个文件当封面。
5. **三渲染器接入**：EPUB = 封面图进 manifest（`properties="cover-image"`）+ `<meta name="cover">` + `cover.xhtml` 用真图 + 章/卷封进 `images/`；PDF = `build_cover_stream` 支持图片页（现有 `collect_images` 原料已在）；DOCX = 补封面页并挂图。
6. **缺图不许静默**（P1 #7 口径）：`resolve_asset_ref` 失败 → 任务 `failed` 且错误信息点名缺哪个文件；不许出"看起来成功但少图"的产物。

### B-c｜渲染器层级补齐（解 B；= 11-05 第 2、3 步）
DOCX 加 `卷=outlineLvl 1 / 章=outlineLvl 2`（Word 导航窗格成树）+ 封面页；快照原生 txt/html/md 与前端另存为口径对齐（`════ 卷名 ════` / `<h2 class="volume">`+章降 `<h3>` / `#书名 ##卷 ###章`）；EPUB nav 的卷组标题由 `<span>` 改「可点 `<a>` + 嵌套 `<ol>`」，指向卷页，这样阅读器目录是真父子。**顺手把 `EpubChapter.volume` 那条写着「DOCX 卷标」的假注释改对**——假注释就是本案成因。

### B-d｜两条导出路径收敛（防"另存为仍然丢卷丢封面"的尾巴）
`useExportActions.ts:186-191/296-301/324-329` 三处 `volume: c.volume || ''` 只认遗留字段 → 新树书恒空。两个选项见 §4 P5。

## 5. 可证伪判据（做完拿这些验，不看"感觉对了"）

1. **顺序**：对同一本书，产物章节序列 == 树面板自上而下可见序列（先序）；卷标题后紧跟其子章。
2. **不丢内容**：所有 `kind='章'` 正文 + P1 的卷首语，字符数与快照一致（差 0）。
3. **不造假**：旧模型书（无 parent_id）产物与改动前逐字节一致；`schema_ver=1` 版本产物无封面但正文/结构正确。
4. **EPUB**：解包断言 `nav.xhtml` 出现 `<a href="vol_0.xhtml">卷 1</a>` + 嵌套 `<ol>` 挂 章 1；`content.opf` 含 `properties="cover-image"` 与 `<meta name="cover">`；`OEBPS/images/` 含卷 1 那张图。
5. **DOCX**：解 `document.xml` 断言卷段 `outlineLvl w:val="1"`、章段 `="2"`；Word/WPS 导航窗格人工核对成树。
6. **PDF**：封面页含图片 XObject（内容流出现 `Do` 图像绘制）；目录页出现卷层缩进。
7. **缺图诚实**：删掉封面图文件后重导 → 任务 `failed` 且错误点名该文件，不产出残缺文件。
8. **六格式全跑 + 实开**：epub/pdf/docx/html/txt/md 各导一次，Apple Books / Acrobat / Word 实际打开核对（测绿只是必要条件）。
