## 1. 现状诊断（代码可核对，不形容词）

### 1.1 排版：只有"参数",没有"规范"
| 事实 | 位置 | 后果 |
|---|---|---|
| EPUB 样式表里 **没有** `@page`、`widows/orphans`、`hyphens`、`text-align: justify`、`@font-face` | `writing/mod.rs` STYLE_CSS（grep 零命中） | 段落在阅读器里自由断行，孤行寡行满天飞；作者选的字体在别的设备上可能根本没有 → 静默换字面 |
| DOCX 只有一条写死的 `sectPr`（A4 + 上下左右 1440twips），**无页码域、无页眉、无 `w:widowControl`、无 `w:docGrid`** | `docx_export.rs:188` | Word 打开是"一篇长文"，导航窗格有层级但页面不像书；跨页标题悬在页底 |
| PDF 有页脚页码 `i / 总-1`，但**无章节页眉、无禁则（kinsoku）、无标点挤压** | `pdf_export.rs:440-454` | 有底版没书版；中文标点在行首行尾不受约束 |
| 版式参数只有 8 个（字号/行距/段距/字体/西文字体/缩进/宽/纸色），**没有"书档"概念**：页边距、版心比例、标题层级比、章节起始页样式、页码样式一律不可设 | `layout.rs::BookLayoutSpec` | 无论导给谁，都是一套默认长相 |

### 1.2 导出库：有 API，没有管理面
后端已存在 `list_export_artifacts / reveal_artifact / copy_artifact_to / retry_export_job / dismiss_export_job`，
但界面侧（`PublishedScenesPage`）只把它们做成**版本行里的几个 chip + 打开/复制**。缺：

- **产物没有独立视图**：不能按格式/状态/时间跨版本、跨作品看全部产物。
- **不能删单个产物**（只能连带版本删；`delete_work_version` 才有"同时删文件"勾选）。
- **看不出过期**：定稿版换了、快照或排版改了，旧产物文件仍是老内容，界面无任何标记 → 用户会把过期文件当最新交出去。**这是最危险的一条**。
- **看不出存储占用**（作品库多大、哪本书占多少、失败任务留没留残件）。
- **失败没有集中处置面**（任务条能重试，但要看清"哪几本哪一版哪个格式坏了"得逐本点）。
- **没有导出历史**（什么时候导的、用哪套版式、含多少图）→ 出问题时无法回溯。

### 1.3 概念与页面
`PublishedScenesPage.tsx` 1367 行一个文件，书卡 / 版本行 / 产物 chips / 任务队列 / 三个对话框全塞在一起；
产物被压在版本行内联展开里——**密度太低，管理动作无处放**。这不是样式问题，是缺一个"库"的层级。

## 2. 目标概念模型（四个名词，职责单一）

```
作品 Work ──┬── 版本 Version（锁定即定格：正文 + 封面引用 + 插图字节 + 书目元数据）
            └── 交付 Deliverable ＝ 版本 × 格式 × 版式档 × 渠道规格 的一次导出
                     │
                     ├── 状态：queued / running / ready / failed / stale（过期）
                     └── 指纹：{版本内容哈希 + 版式哈希 + 资源清单哈希}

排版档 LayoutPreset（作者可管理的"书长什么样"，可多套并复用）
```

三条硬结论：
1. **交付物是一等对象**，不再当成"版本行上的几个 chip"。管理面围绕它设计。
2. **`stale` 必须自动判定**：交付时的指纹 ≠ 当前版本/版式的指纹 → 标"过期"，而不是等用户猜。
3. **排版档与渠道规格分开**：排版档管"这本书长什么样"，渠道规格（微信读书/Kindle/豆瓣阅读/纸印/EPUB 校验）管"投递到哪、约束是什么"，一次导出 = 版式档 + 渠道规格。

## 3. 页面重做：三层导航（新 IA）

```
完结作品（顶部四个入口，产物/任务不再是版本行的附庸）
│
├─ 【作品】默认视图：书卡网格
│    卡面 = 封面(真图) · 书名 · 状态 · 最新 vN · ✅定稿 · 交付数 · ⚠过期数 · 占用
│    点入 → 书详情（左：版本时间线；右：所选版本的详情与交付列表）
│
├─ 【交付库】（新增，这就是你要的"管理导出库"）
│    工具条：搜索 · 筛选(格式/状态/是否过期/时间) · 排序 · 批量操作
│    表格行：书名 · 版本 · 格式 · 版式档 · 大小 · 生成时间 · 状态徽标 · 〔打开〕〔复制〕〔重导〕〔删除〕
│    批量：重试全部失败 · 清理全部过期 · 打开所在文件夹 · 导出交付清单(CSV)
│    侧栏：作品库占用（总大小 / 按书 / 按格式）· 失败聚焦 · 无产物作品清单
│
├─ 【排版】（新增：版式档管理，不再是设置抽屉里那 8 个控件）
│    左侧版式档列表（书档/轻经典/宋体正文/宽疏排版…）+ 右侧实时预览（真渲染一页，不是示意图）
│    可管：页边距与版心比、正文字体(含内嵌字体)、字号阶、行距、段距、首行缩进、
│          标题层级比、章节起始页样式、页码样式与位置、奇偶页与书口、孤行控制、对齐策略
│    书级绑定：每本书可指定默认版式档（延续"书级覆盖 > 全局"的既有口径）
│
└─ 【任务】后台队列（保留，升为独立页签：进行中/排队/失败，可重试可清空）
```

版本详情里新增（都是"发掘出来的新需求"，成本小价值高）：
- **资源回执**：这一版定格了几张图、跳过了哪些节点、用了哪套版式（缺图点名）。直接复用已落地的定格表与 `BookMeta`。
- **版本对比**：与上一版的章数/字数差、新增·删除·改动的章清单（数据早就在快照里，只是没算给 UI）。
- **旧版如实说明**：已做（`schema_ver` 提示），继续保留。

## 4. 排版要做到什么程度才算好（逐条可测，不说"精美"）

**L1 结构层（三种格式都要）**
1. 章节起始页：每章从新页/新栏开始，章题与正文间距固定（现在 DOCX/HTML 无此约束）。
2. 标题层级比例：由版心宽度反算，正文与标题成比例，**不许标题比正文小**（PDF 已等比，其他格式要跟上）。
3. 卷页：卷是独立一页（本轮已做），卷页不带页眉、页码不计数或单独计数（要定）。

**L2 中文排版层**
4. 孤行寡行控制：`widows:2; orphans:2`（EPUB/HTML）、`w:widowControl`（DOCX）、PDF 同规则。
5. 标点禁则 kinsoku：行首禁则（，。、；：？！”』）与行尾禁则（“『）不落单（EPUB 用 `line-break/word-break`，PDF 自己做禁则表）。
6. 对齐：正文默认两端对齐 + 允许西文断词，缩进与段距二选一（不许同时大段距 + 缩进）。
7. 中西文混排：中西文之间留空（`text-spacing` 自己做）、数字用表意数字可选。
8. **字体内嵌**：EPUB 打包 `@font-face` 字体子集（否则你选的宋体在别人的机器上就是伪选项）。

**L3 书体层**
9. 页码：首页不计、奇偶页码分列外角、目录罗马数字正文阿拉伯（PDF/DOCX；EPUB 交给阅读器但提供 `page-list`）。
10. 页眉：偶页书名 / 奇页章题（可关）。
11. 题头页：书名页 → 版权页 → 题词 → 目录 → 正文（版权页已部分实现，要成结构）。
12. 渠道规格预设（P2）：按目标平台约束（图片尺寸/目录深度/字体/校验规则）选预设一键导。

> 每一层都要有**产物级断言**测试（解包搜样式/域代码、PDF 断内容流），不是肉眼看“像不像”。

## 5. 分期（每期都能独立验收，不做半套）

| 期 | 内容 | 验收 |
|---|---|---|
| **R5-a 交付库**（先做，因为它就是你要的“管理”） | `stale` 判定与标记；交付库页签（筛选/批量/占用/失败聚焦）；单产物删除；导出历史与回执 | 能一眼看出哪本哪个格式过期；能批量清理；删除不连带误删 |
| **R5-b 排版档体系** | `LayoutPreset` 表与 CRUD；书级绑定；版式参数扩充（页边距/版心/标题阶/页码/页眉/孤行/对齐）；实时预览 | 改预设 → 重导 → 三格式产物里能断到对应样式与域 |
| **R5-c 中文排版层** | L2 全部 8 条 + EPUB 字体子集内嵌 | 产物断言 + 真阅读器实开验收清单 |
| **R5-d 书体层** | 题头页/版权页/页码/页眉/卷页不计码（L3） | 目录页码与正文实际页一致（PDF/DOCX 可验） |
| **R5-e 页面重做收尾** | 四页签新 IA 落地，`PublishedScenesPage` 拆分；旧 `FinishedPendingBand` 等临时件删除 | 旧结构零残留；测试全绿 |

**实施顺序建议：R5-a → R5-b → R5-c → R5-d → R5-e**。理由：先把“管理”补上（今天最缺），
再把排版体系立项（否则排版参数无处安放），页面重构放最后，避免反复改同一堆代码。

| # | 议题 | 我的默认值 |
